# TinyNet.Example

Небольшое веб-приложение для заметок: одна страница со списком заметок и формой, обычные
HTML-формы, без JavaScript. Показывает, как части фреймворка складываются в настоящее
приложение: слои конфигурации, времена жизни в DI, глобальный middleware, группа маршрутов с
фильтром, синхронные и асинхронные обработчики. Места кода, связанные с фреймворком,
прокомментированы на английском и русском.

[English version](README.md)

---

## Запуск

Рабочая директория важна — `config.json` ищется относительно неё:

```bash
cd TinyNet.Example
dotnet run
```

Откройте `http://localhost:5768` в браузере.

## Как это работает

| Запрос                     | Что происходит                                                                 |
|----------------------------|--------------------------------------------------------------------------------|
| `GET /`                    | Страница: заголовок из конфигурации, заметки, форма добавления                 |
| `POST /notes`              | Форма добавления; редирект `303` обратно на `/` или на `/?error=title`         |
| `POST /notes/{id}/delete`  | Кнопка удаления заметки; редирект `303` обратно на `/`                         |
| `GET /health`              | `ok` — для балансировщика или быстрой проверки                                 |

После отправки формы сервер отвечает редиректом, поэтому обновление страницы не отправляет
форму повторно (Post/Redirect/Get). Заметки хранятся в памяти и пропадают при перезапуске.

## Состав

| Файл                                | Содержимое                                                       |
|-------------------------------------|------------------------------------------------------------------|
| `Program.cs`                        | Конфигурация, сервисы, middleware и дерево маршрутов             |
| `Pages/NotesPage.cs`                | Класс-обработчик: страница, добавление и удаление заметки        |
| `Pages/Layout.cs`                   | HTML-каркас страницы и экранирование HTML                        |
| `Pages/Form.cs`                     | Разбор тела `application/x-www-form-urlencoded`                  |
| `Filters/SameOriginFilter.cs`       | Отклоняет формы, отправленные с другого сайта                    |
| `Middlewares/RequestIdMiddleware.cs`| Пишет в лог каждый запрос с его id и временем                    |
| `Services/`                         | `NoteStore` (singleton), `RequestId` (scoped)                     |

## Что показывает каждая часть

| Возможность                          | Где                                                                                                      |
|--------------------------------------|----------------------------------------------------------------------------------------------------------|
| Слои конфигурации                    | `Example:Title`: `AddDefault` в `Program.cs` → `config.json` → `TINYNET_Example__Title`                   |
| Singleton-сервис                     | `NoteStore` — общий для всех запросов, поэтому потокобезопасный                                          |
| Scoped-сервис                        | `RequestId` — один на запрос; middleware и подвал страницы показывают одно и то же значение              |
| Класс-обработчик                     | `AddGet<NotesPage>("/", h => h.Index)`: регистрирует фреймворк из маршрутов, по одному на запрос         |
| Обработчик без класса                | `AddGet("/health", (request, context) => ...)`: в DI ничего не регистрируется                            |
| Синхронные и асинхронные обработчики | `Index` и `Delete` возвращают `HttpResponse`; `Create` читает тело и возвращает `Task<HttpResponse>`      |
| Фильтр группы, обрывающий запрос     | `SameOriginFilter` на `/notes` отвечает `403`, не вызывая обработчик                                     |
| Глобальный middleware                | `RequestIdMiddleware` пишет id запроса, метод, путь, статус или исключение и время                       |
| Чтение данных запроса                | `GetFromQuery("error")`, `GetFromRoute<int>("id")`, `GetFromHeaders("Origin")`, `BufferBodyAsync()`       |
| Сборка ответа                        | HTML через `.Bytes(...)`, редирект через `.Status(303).AddHeader("Location", ...).Empty()`, `.Text(...)` |
| Автоматические ответы                | `400` на нечисловой `{id}`, `405` на `GET /notes`, `404` на неизвестный путь                             |

Привязки форм и шаблонов во фреймворке нет намеренно: обработчик сам читает тело и разбирает
форму (`Pages/Form.cs`), а страница — интерполированная строка. Каждое значение от
пользователя проходит через `Layout.Encode`, прежде чем попасть в HTML.

```bash
curl -i -X POST http://localhost:5768/notes/abc/delete                          # 400, не число
curl -i http://localhost:5768/notes                                             # 405, только POST
curl -i -X POST http://localhost:5768/notes -H "Origin: http://evil.example" -d "title=x"   # 403
```

## Настройки

Любой ключ можно переопределить через окружение, не трогая файл; `__` означает `:`:

```bash
TINYNET_Server__Port=8080 TINYNET_Example__Title="Мои заметки" dotnet run
```
